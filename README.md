## How to Run

### Run the Application
Start the local development server:
```bash
ng serve
```
*Open [http://localhost:4200/](http://localhost:4200/) in your browser to view the app.*

### Run the Tests
Execute the unit tests (there is a small delay untill all tests run showing 0 passed and 0 run):
```bash
ng test
```
